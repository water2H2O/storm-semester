## 1. 画面实测：录前必看（我已实际渲染过）

我把 demo 用无头浏览器跑起来抓了真实画面，发现 4 个会直接影响成片质量的问题：

### ① 黑雨档极暗，四周大面积纯黑

`black` 档的参数是雾色 `0x140c1f`、曝光 `0.80`、主光 `0.16`，城市只占画面中间一条，上下左右是大片纯黑。**这种画面经 YouTube 压缩后会糊成一团**，评委在普通笔记本亮度下可能看不清城市细节。

**处理**：剪辑时整体亮度/对比 +8~12%，或者把黑雨镜头压短（8–10 秒内切走）。

### ② 「本周」「未来三周」在首屏折叠线以下

面板打开时只能看到「今日 / 下一场风暴 / 现在做这一件」，**必须向下滚**才能拍到「本周」7 格天气和「未来三周」时间轴。这两块是产品的主要卖点之一（尤其"越远越模糊"的设计），不拍等于没做。

**分镜表已加滚动镜头（0:46–1:00）。**

### ③ 黑色暴雨的图标是月亮 🌑

`engine.js` 里 `black` 档的 icon 是 `🌑`（新月）。视频第一个镜头就是这个状态，一个紫色月亮配"黑色暴雨"四个字，评委大概率读不懂。

**建议一行改掉**（`engine.js:46`）：

```js
{ key: 'black', min: 18, label: '黑色暴雨', icon: '🌧️', signal: 'BLACK' },
```

小雨是 `🌧️` 会冲突，可同时把小雨改成 `🌦️`。这是 1 分钟的事，但对首帧观感影响很大。

### ④ 城市里的悬浮文字气泡在 1080p 缩到 720p 后读不清

首屏有两个 3D 文字气泡（"BUHACK 2.0 · 48 小时线上黑客松"、"天文台 · 黑色暴雨 · 今天 5 个事项到期"）。**别指望它们传达信息**，信息要靠字幕和旁白。

### 另外两个好用的点

- 「标记完成」按钮是**醒目的粉色**，天然是视觉引导点，适合做片头之后的第一个动作。
- 城市态左上角有**电视台风格的警告角标**（"黑色暴雨警告 / 天文台发出 · 生效中"），这个细节值得在片头给 2 秒特写。

## 3. 录制前 12 项检查

- [ ] **新开浏览器配置文件**（Chrome 头像 → 添加 → 不登录）或用 `Ctrl+Shift+N` 隐私窗口
- [ ] **F11 全屏**，`Ctrl+Shift+B` 关书签栏
- [ ] **系统缩放 100%**，录制分辨率 1920×1080
- [ ] 关掉微信 / QQ / 邮件通知，专注助手开「仅闹钟」
- [ ] 关掉其它标签页和窗口
- [ ] URL 带 `?today=2026-11-13&lang=en`（`lang=en` 强制英文，避免你自己之前点过中文被记住）
- [ ] 确认首屏是 **黑色暴雨 · 今天有 5 个事项到期**
- [ ] **清一次 localStorage**：F12 → `localStorage.clear()` → 刷新（保证 5 件都没被勾掉）
- [ ] 鼠标移动要慢，**点击后停 0.5 秒**再动
- [ ] 配音的话先测麦克风（-12 ~ -6 dB，别爆音）
- [ ] 先空跑演练 1 遍，不录
- [ ] 确认窗口内没有真实姓名 / 学号 / 私人日历

> 直接双击 `index.html` 用 `file://` 打开就能跑——代码里没有 `fetch`，种子数据内联在 `store.js`，不依赖服务器。想更像"真网站"可以 `python -m http.server 8000` 后开 `http://localhost:8000/index.html?today=2026-11-13`。

## 4. 分镜表（成片时间轴，2:35）

界面按钮文案已核对代码，照着点。**左列是成片时间，不是录制时间。**

| 成片时间 | 你做什么 | 屏幕上是什么 | 字幕 |
|---|---|---|---|
| **0:00–0:13** | 什么都不点，让镜头自己环绕 | 香港城市 + 黑色暴雨 + 左上角「黑色暴雨警告」角标 | Five deadlines… / My calendar lists every date. / It never tells me what to start today. |
| **0:13–0:17** | 点底部 **`View semester details ↑`** | 面板向上滑入 | So I turned my semester into a weather forecast. |
| **0:17–0:31** | 停住不滚 | 大标题「黑色暴雨」+ 学业负担指数 + 「下一场风暴」卡片 | Every unfinished deadline adds pressure… / Clear skies or a black rainstorm… |
| **0:31–0:46** | 鼠标移到 **`Do this next`** 卡片 | 单条建议 + 课程 + 「建议开始日已过 7 天，现在开始也有帮助」 | Next storm… / One task, chosen by preparation window… |
| **0:46–1:00** | **向下滚动**，停在「This week」和「Next three weeks」 | 7 格天气条 + 21 天时间轴，14 天后明显变淡 | The whole semester at a glance. / The further out, the vaguer it gets… |
| **1:00–1:14** | 滚到发生型事项（考试/小测），勾 **1–2 个**checklist | 准备度进度条上涨 | An exam is not something I submit. / So I track preparation instead… |
| **1:14–1:28** | 拖一个事项的 **`Wt`** 滑块，慢，从左到右 | 时间轴 / 本周天气实时重画 | Every schedule is different. / So weights and preparation windows are mine to adjust. |
| **1:28–2:00** | 滚回顶部，连点 **`✓ Done`** 5 次。每次自动退回城市 2.4 秒再回来 | **高光段**：黑雨 → 八号风球 → 雷雨 → 多云 | Now the part that matters… / Each completed deadline removes its pressure. / The city clears… / The forecast becomes feedback. |
| **2:00–2:10** | 点 **`Import .ics calendar`**，出现预览后取消 | 导入预览面板 | Existing calendars import too — in the browser, no account. |
| **2:10–2:18** | 点右上角城市切换（通用岛 ↔ 香港） | 城市淡出淡入，天气不变 | A generic island, or Hong Kong with its warning signals. |
| **2:18–2:35** | 回到城市态停住，叠片尾字 | 城市 + 项目名 + 仓库链接 | This is a planning tool, not a diagnosis. / See the storm early. Choose your next step. |

### 剪辑要点

1. **1:28–2:00 的 5 次完成**，原始素材会很长（每次 2.4 秒往返）。**加速到 1.5–2 倍**，保留第 1 次和最后 1 次原速，中间 3 次加速——观众要的是"一路放晴"的节奏，不是看你点 5 次。
2. 片尾叠字：`Storm Semester · 学期风暴` + `github.com/water2H2O/storm-semester`，停 3 秒以上。
3. **开头不要放 logo 动画**，前 3 秒已经在说问题。
4. 每段切换加 0.2 秒交叉淡化，别硬切。

## 5. 字幕

成品字幕已写好：**[video-subtitles.srt](video-subtitles.srt)**，22 条，时间轴与上表一一对应，每条「英文一行 + 中文一行」，总长 2:35。

**导入：**剪映 → `文本` → `本地字幕` → 选 SRT，自动铺到时间轴。

**注意：**
- 字幕放底部安全区（距底 8–10%），**别压在底部天气条上**。
- 界面现在默认英文，**纯英文字幕即可**：把 SRT 里的中文行删掉最干净。要双语的话中文行字号调小一级。
- 界面上出现的中文按钮词，英文字幕用**动作描述**而非硬翻：`查看学期详情` → "open the semester panel"，`Mark complete` → "mark it complete"。

## 6. 配音（方案 B）

**顺序：先录屏 → 再配音。** 别一边说一边录，节奏一定乱。

1. 录屏定剪到 2:35，锁定时间轴。
2. 按 SRT 每条时间读英文句，Audacity 或剪映内置录音。
3. 每句留 0.2 秒气口，语速比平时慢 10%。
4. 背景音：YouTube Audio Library 或 Pixabay Music 找无版权、无人声的曲子，音量 **-26 dB**，别盖过旁白。
5. 英文旁白就是 SRT 的英文行，按顺序连读即可。

## 9. 常见坑

| 坑 | 后果 | 预防 |
|---|---|---|
| 用了默认日期 | 首屏「阴 / 0 个到期」，台词全错 | 检查清单第 6 项 |
| 忘了滚到「本周 / 未来三周」 | 主要卖点没拍到 | 分镜 0:46–1:00 |
| 5 次完成没加速 | 拖成 3 分半，超时 | 加速 1.5–2 倍 |
| 只靠 YouTube CC 字幕 | 评委不开 CC = 没字幕 | 字幕烧进画面 |
| 黑雨档太暗没修 | 城市糊成一团 | 亮度 +8~12% |
| 书签栏没关 | 不专业，还露私人书签 | 隐私窗口 + 全屏 |
| 上传卡在截止前 30 分钟 | 处理延迟，链接无效 | 提前 8 小时 |
| 时长超 3 分钟 | 可能被拒收 | 导出前看时长 |
